# THU-BDC 股票策略当前模型审计

## 当前结论

当前最强可复现方案不是理想的 Top5/Top10 组合模型，而是 rank1-specialist：它能把模型第一名的 14 周平均收益推到约 10.15%，但分散到 5 只后收益下降。这说明当前模型具备一定识别强势候选的能力，但还没有稳定识别一组强势股票的能力。

核心问题不是单纯“数据少”或“模型完全无效”，而是：

1. 事件/题材/资金数据已经接入，但模型主要仍依赖量价波动类特征。
2. Top1 信号强于 Top2-Top5，候选池排序后半段质量明显不足。
3. 直接增加更多 TuShare 字段会带来噪声；技术因子和板块映射回测已经验证过会降低效果。
4. 当前 LightGBM LambdaRank 是横截面排序模型，不是专门优化 Top5 召回和组合收益的模型。

## 当前模型结构

正式脚本：`code/src/train_current_fusion_submission.py`

当前正式模型包含两个 LightGBM Ranker profile：

1. `long_rank`
   - 数据：长历史/基础行情特征
   - 权重：0.2
   - relevance：rank
   - 特征数：821

2. `extra_rank`
   - 数据：基础行情 + 热榜 + 涨跌停 + 龙虎榜 + 融资融券
   - 权重：0.8
   - relevance：rank
   - 特征数：1034

融合方法：

- 每个 profile 对最新截面 300 只股票打分
- 每个 profile 的分数转为日内百分位 rank
- 融合分数 = 0.2 * long_rank_pct + 0.8 * extra_rank_pct
- 过滤：`last_close_pos > 0.35` 且 `ret_20 > -0.25`
- 取融合分数前 5
- 当前权重模板：`[0.999996, 0.000001, 0.000001, 0.000001, 0.000001]`

## 训练标签

标签是未来 5 日开盘到开盘收益：

`label_return = open_t5 / open_t1 - 1`

也就是下一个交易日开盘买入，第 5 个未来交易日开盘卖出。

训练时用 `label_known_date <= cutoff`，避免未来泄露。

## 模型效果摘要

### 市场上限

最近 14 周真实 Top5 等权：

- 平均：21.636%
- 14/14 周超过 10%

说明市场机会存在。

### 普通 Top5 融合方案

最佳分散类融合：

- 平均：约 6.08%
- 10% 命中：6/14
- 问题：第 2-5 名质量不足

### rank1-specialist

- 平均：约 10.15%
- 10% 命中：6/14
- 最差：约 -18.78%

说明模型第一名有一定能力，但风险极集中。

## 特征重要性观察

当前 artifact 中，最重要的特征主要是：

- 振幅均值 cross-sectional z/rank
- ATR/波动率
- 5 日行业相对收益
- PE/市值/流通市值
- 距涨停价距离
- 近期涨停/接近涨停次数

事件特征在 extra 模型中有一定重要性，但不居于最前：

- `f_ths_hot_rank_score_mean_30_cs_rank`
- `f_ths_hot_listed_count_120_cs_z`
- `f_top_listed_count_20_cs_rank`
- `f_margin_fin_balance_log_cs_z`
- `f_limit_list_up_count_10_cs_z`
- `f_limit_seal_amount_cs_z`

这说明模型确实用了部分事件数据，但事件特征还没有压过量价噪声。

## 当前主要问题

1. 模型弱点不是 Top1，而是 Top5/Top10 召回不足。
2. 事件/题材数据处理还偏浅，没有形成题材生命周期、扩散强度、龙头-跟随关系。
3. LightGBM ranker 优化的是逐日排序，不直接优化组合收益和 TopK 召回。
4. 直接堆接口会过拟合/加噪，已验证技术因子和板块映射会拖累。
5. 目前没有新闻语义、公告语义、题材文本 embedding，热榜原因字段还没有被 NLP 结构化使用。

## 下一步真正该改的方向

1. 候选召回模型
   - 先训练二分类/多标签模型预测 `future_return >= 10%`、`top10`、`top20`
   - 目标从平均收益改成 recall@30 / recall@50

2. 二阶段排序
   - 第一阶段生成 30-50 只候选
   - 第二阶段只在候选池内排序 Top5

3. 题材生命周期特征
   - 概念连续上榜天数
   - 热度加速度
   - 同概念上榜股票数量
   - 概念内最强股票涨幅
   - 股票是龙头还是跟随

4. 事件共振特征
   - 热榜 + 涨停
   - 热榜 + 龙虎榜净买入
   - 涨停 + 龙虎榜机构净买入
   - 融资余额增加 + 热榜上升

5. 文本特征
   - 解析 `ths_hot_reason`
   - 抽取关键词：AI、芯片、创新药、并购、国资、订单、业绩、政策等
   - 做主题频次和股票主题强度
